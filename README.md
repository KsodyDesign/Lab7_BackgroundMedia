# Лабораторная работа №7. Фоновое воспроизведение медиа и управление через MediaSession + уведомления

Студент: Ретунский Савелий

## Описание проекта
Приложение разработано в рамках лабораторной работы №7 по курсу мобильной разработки для ОС Android.

Цель работы — реализация фонового сервиса (`Foreground Service`) с поддержкой воспроизведения плейлиста, автоматическим переходом между треками, двусторонней синхронизацией интерфейса через `BroadcastReceiver`, а также интеграцией системных уведомлений и `MediaSession`.

### Реализованный функционал:
1. **Модель плейлиста (`TrackInfo.kt`)**:
   - Список треков с ресурсами из `res/raw` (`sample_audio_1`, `sample_audio_2`, `sample_audio_3`; три WAV-мелодии по 8 секунд) и метаданными (название, автор).
   - Поддержка переходов «Следующий трек» (`Next`) и «Предыдущий трек» (`Previous`).
   - Автоматический переход к следующей композиции по завершении текущей (`MediaPlayer.OnCompletionListener`).

2. **Фоновый сервис (`MediaService.kt`)**:
   - Запуск в режиме `Foreground Service` с выделенным каналом уведомлений (`NotificationChannel`).
   - Использование `MediaSessionCompat` для системного контроля воспроизведения (включая внешние кнопки гарнитуры и экран блокировки).
   - Информативное уведомление со стилем `MediaStyle`, кнопками управления («Назад», «Играть/Пауза», «Вперед») и метаданными медиасессии.
   - Освобождение ресурсов `mediaPlayer.release()` перед загрузкой новых треков и при завершении сервиса.

3. **Синхронизация с UI (`MainActivity.kt`)**:
   - Отправка и получение статуса («Воспроизводится», «На паузе», «Остановлено») и названия активного трека через `LocalBroadcastManager`.
   - Динамическое обновление состояния экрана в реальном времени.

## Сборка и запуск
- Минимальная версия Android SDK: API 24 (Android 7.0)
- Целевая версия Android SDK: API 37
- Язык разработки: Kotlin
- Готовый установочный файл приложения: `app-debug.apk` в корне репозитория.
